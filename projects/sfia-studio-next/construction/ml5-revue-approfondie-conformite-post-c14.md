### 1.1. Vision et résultat utilisateur

Le Pilote dialogue avec Nora dans le sas, le projet, les documents, les décisions et le bilan. Nora comprend l'intention, qualifie la complexité et les restrictions, choisit des moyens proportionnés, consulte les sources utiles, réconcilie faits/contradictions, peut reprendre une investigation interrompue, et produit une réponse, un document ou un contrat technique complet. D7 observe et réconcilie la tentative, reçoit/collecte la remise identifiée ; D9 vérifie les faits Git indépendamment si applicable ; D8 confronte preuves et critères ; Nora rend un avis cognitif global unique, consultatif, puis le Pilote peut en discuter. MCP dans Cursor administré par le propriétaire, vérifié uniquement si nécessaire. F2 reporté à recette UX, pas supprimé. Le résultat recherché est l'usage réel end-to-end et non un empilement de micro-cycles ou de démonstrations locales.
