## 3. Intention / Executive summary

**Nora Cognitive Completion** est une **extension cognitive** de SFIA Studio Product Completion.

Product Completion a déjà défini **CE QUE** SFIA Studio attend fonctionnellement de Nora (qualifier, challenger, proposer LPS/Trajectory/Options/Recommendation, préparer EC sans autorité, analyser Evidence, replanifier, respecter HD/Confirmation/authority).

Ce C1 détermine **quelles capacités cognitives** Nora doit posséder pour **tenir réellement** ce rôle avec une autonomie cognitive et une qualité se rapprochant de l’expérience externe ChatGPT, **tout en cohabitant** avec le runtime métier gouverné déjà construit.

**Chaîne directrice (obligatoire) :**

```text
Product Completion
→ rôle Nora attendu
→ responsabilités / comportements Nora
→ capacités déjà couvertes
→ gaps cognitifs (faits / hypothèses)
→ besoins cognitifs cibles
→ opportunités OpenAI candidates
→ frontières SFIA Governance
→ preuves / evals
→ trajectoire produit candidate
```

**Principe directeur :** ne **pas** partir de « que peut faire OpenAI ? » pour définir Nora.

**Formule d’autonomie :**

```text
MORE COGNITIVE AUTONOMY ≠ LESS SFIA GOVERNANCE
Autonomie cognitive ≠ autonomie d’autorité
Nora raisonne / challenge / recommande — Nora ne décide pas
```
