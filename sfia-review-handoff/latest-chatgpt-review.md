## 8. Recommendation semantic definition

A **Lifecycle Recommendation** is an attributable, structured, currentness-qualified Product cognition object that advises the Pilot about a lifecycle intent without granting authority.

It is NOT eligibility, NOT HumanDecision, NOT Confirmation, NOT ExecutionContract authority, NOT construction Morris GO.

Candidate Product vocabulary (may be refined in Delivery):

- Intent: `FINALIZE_CURRENT_CYCLE` | `NEXT_CYCLE`
- Envelope: SFIA-owned fields stamped after cognition validation
- Durability: EpistemicItem `type: "Recommendation"` (preferred) carrying structured statement / refs
- Read path: PilotLifecycleProjection (or bounded companion DTO) exposes **current** Recommendation for selected cycle context

## 9. FINALIZE intent

**FINALIZE_CURRENT_CYCLE**

Meaning: Nora recommends that the Pilot consider entering FINALIZE for the current relevant CycleInstance.

NOT:
- canFinalize
- FINALIZE HumanDecision
- FINALIZE transition
- canComplete / completion

Doctrine alignment (implemented): FINALIZE HD may be accepted while obligations remain pending; `finalizeAccepted ⊂ canComplete`. Therefore FINALIZE Recommendation may legitimately exist when exit obligations are still PENDING/MISSING/BLOCKING.

## 10. NEXT_CYCLE intent

**NEXT_CYCLE**

Meaning: after appropriate trajectory/lifecycle state, Nora recommends a specific next cycle target to the Pilot.

Target binding preference:
1. candidate CycleInstance id (strongest)
2. else cycleTypeId + trajectory context only if deterministic resolution is Product-valid

NOT:
- candidate existence alone
- canStart
- active cycle
- D5 SOLICIT_MORRIS_GO_FOR_NEXT_CYCLE / solicit_morris_go

Candidate remains non-active until Pilot START succeeds.
