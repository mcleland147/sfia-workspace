## 13. Validation protocol 15/15

### Critères communs (individual validation)

Pour chaque CKC, avant recommandation de promotion :

1. Conformité au format canonique (noyau + depth profile).
2. Valeur cognitive réelle (change le raisonnement GPT).
3. Absence de duplication massive avec méthode §4.
4. Anti-checklist (pas de script de questions).
5. Questions **adaptatives** (exemples, pas obligations).
6. Maturité explicable (bandes, pas %).
7. Anti-claims corrects (surtout authority / Delivery / baseline).
8. Transitions **conditionnelles**.
9. Aucune autorité implicite.
10. Compatibilité routing (chemin / fallback / déclaration couverture).
11. Compatibilité template (fiche consultation, hors contrat Cursor).
12. Cas clair documenté.
13. Cas ambigu documenté.
14. Cas négatif / anti-use documenté.
15. Cohérence avec méthode du cycle §4.x.
16. Tests documentaires unitaires du contrat.

### Cross-contract validation (15/15)

1. Homogénéité du noyau (mêmes sections OBL).
2. Pas de contradiction terminologique entre contrats.
3. Transitions croisées non circulaires / non automatiques.
4. Depth profiles cohérents avec criticité.
5. Fallback retirement plan (quand 15/15 `validated`).
6. Aucun contrat n’introduit d’authority Cursor.
7. Revue transversale humaine (ChatGPT + Morris).

### Authority

**Validation finale = Morris-gated.**
ChatGPT / Cursor peuvent **préparer** la preuve ; seuls Morris **adopte / valide / refuse**.
