## 4. Architecture principles

Dérivés de C1/C2/framings 30–37 / Build Doctrine :

1. **Project ≠ Cycle** — Project durable porte LPS ; CycleInstance porte qualification/session épistémique.
2. **Recommendation ≠ HumanDecision** — Nora propose ; Pilote décide ; jamais auto-promotion.
3. **ProjectTrajectory ≠ Roadmap** — Trajectory = état projet vivant ; Roadmap = construction convergence.
4. **CKC doctrine ≠ CKC method assets ≠ authority** (FA-R02) :
   - **V3-F01 CKC** = doctrine Studio v3 **VALIDATED** (couche cognitive canonique d'un type de cycle) ;
   - **current method/sfia-fast-track CKC assets** = candidate / incomplete coverage / process guidance externe ;
   - CKC **≠** HumanDecision **≠** ExecutionContract **≠** permission **≠** autorité d'exécution **≠** élargissement de scope ;
   - fallback produit cible = **intra-DoctrinePackage v3** · jamais bascule runtime vers v2.6 ;
   - assets method candidate **≠** maturité de V3-F01 elle-même.
5. **ExecutionContract = contrat fonctionnel natif** — native ≠ simplifié · structured ≠ opaque · Markdown Cursor = adapter/projection seulement (CA-PC-14/15/16).
6. **AgentCapability = governance envelope** ≠ catalogue features Cursor ≠ effective authority.
7. **Confirmation after EC inspection when required** — ordre C2 strict : Prepare EC → Inspect EC → Confirmation if required → effective authority / executor sufficiency → Execute · **≠** Build Doctrine A3 historique (RESERVE-GOV-EC-ORDER OPEN · Build Doctrine READ ONLY).
8. **Evidence before claim** — tout terminal Q/R/S produit Evidence avant claim.
9. **Recovery fail-closed** — jamais inventer GO / mémoire / Confirmation / authority.
10. **Doctrine v3 exclusive** — pas de coexistence opérationnelle v2.6/runtime.
11. **Business-first** — Evidence/UX métier avant profondeur technique.
12. **No parallel engine** — un mécanisme générique EC→agent→Evidence ; nouveau type de cycle ≠ nouveau moteur ; pas N moteurs.
13. **Effective authority** (FA-R04 / C1+C2) = intersection de :
    - valid human authorization ;
    - ExecutionContract scope ;
    - AgentCapability / policy ;
    - runtime guardrails ;
    - Confirmation **valide lorsque la frontière applicable l'exige**.
    Confirmation = **consentement borné** (scope + contexte + validité) · **≠** autorité autonome infinie.
14. **Facts ≠ Recommendation ≠ Decision** — epistemology preservée · EpistemicItems matérialisés durables (FA-R03).
15. **Accessibility = MUST** (FA-R07 / C1 · A11Y-PC-01…06) — portée surtout par FC-14 + owners métier concernés · ≠ WCAG claim runtime.
16. **Cycle Catalog Evolvability = MUST** (FA-R06 / C1 J.1·N · CA-PC-26 · CA-PC-31) — 15 types courants ≠ invariant produit.
17. **Git / reuse = MUST** (C1 J.1 · FA-R10) — Git = SoT technique/documentaire · KEEP/ADAPT/COMPLETE/HARVEST avant CREATE · no restart from zero · no parallel architecture · runtime evidence ≠ redéfinition C1/C2 · porté par FC-15 + principles + asset classification.
